INOVAÇÕES

5 patentes que mudam o jogo

Tudo desenhado para uma única coisa: rodar modelos destilados rápido e barato.

Compute-in-Memory

64 tiles de SRAM 256×256 onde a multiplicação MAC acontece dentro da memória. Elimina o gargalo de von Neumann — 1 MAC custa 0.4 pJ vs 4 pJ no NPU tradicional.

Sparse Dataflow Engine

Hardware skipa zeros de pesos quantizados/podados em tempo real. Modelos destilados chegam a 60% de sparsity → 2.3× mais throughput automaticamente.

Mixed-Precision Dinâmico

Cada layer escolhe precisão INT2/INT4/INT8 em runtime via bit-serial. Layers de attention rodam INT8, MLP em INT4, embeddings em INT2 — sem perda de qualidade.

Speculative Decoding HW

Draft model de 100M params embarcado no silício. Gera 4 tokens especulativos em paralelo enquanto o modelo principal valida — 2.8× speedup sem mudar a saída.

128MB SRAM On-die

Cache enorme para um chip edge. Qwen2.5-1.5B INT4 cabe inteiro. Zero acesso à DDR durante inferência → latência sub-millisegundo por token.

Token Streaming Engine

Pipeline de 5 estágios: token N+1 é gerado enquanto N ainda está saindo pelo UART. Time-to-first-token: 18ms. Aplicações de voz ficam imperceptíveis.
