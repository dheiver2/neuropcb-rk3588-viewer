Documentação NeuroPCB

NeuroPCB é a primeira plataforma EDA construída especificamente para projetar e fazer deploy de placas com modelos de IA destilados rodando na borda. Estas docs cobrem desde o quickstart até integração via API e SDK.

🚀 Quickstart · 5 min Crie seu primeiro projeto e faça deploy do Qwen2.5 em uma placa RK3588. 🔌 API REST Integre NeuroPCB no seu CI/CD ou ferramentas internas. ⚡ Deploy via RKLLM Runtime oficial da Rockchip para LLMs no NPU. 🎮 Demo ao vivo Veja a placa RK3588 sem precisar criar conta.

Quickstart · 5 minutos

Em 5 minutos você vai ter um projeto criado, configurado com Qwen2.5-1.5B e comandos prontos para rodar em hardware real (Radxa Rock 5B / Orange Pi 5+).

1 · Crie sua conta

Acesse login.html e crie uma conta grátis com Google, GitHub ou email. Setup leva 30 segundos. Sem cartão de crédito.

2 · Selecione um template

No dashboard, clique em Novo projeto e escolha RK3588 Edge LLM Board. É a placa de referência baseada no chip Rockchip RK3588 (8-core ARM + NPU 6 TOPS).

3 · Explore os 6 modos de visualização

  • 2D Vector — Layout SVG técnico
  • 3D Realtime — Render WebGL fotorrealista
  • X-Ray — Multicamadas translúcidas
  • Thermal — Heatmap baseado em TDP
  • Signal Flow — Animação de corrente nas trilhas
  • AI Inference — Visualizar tensors no NPU

4 · Selecione o modelo na sidebar

Na aba Modelos IA, clique em Qwen2.5 1.5B Instruct. O painel direito mostra benchmarks reais medidos via RKLLM v1.1.4:

  • Decode: 16.5 tok/s
  • Prefill: 195 tok/s
  • RAM: 1.0 GB
  • Contexto: 32K tokens

5 · Copie o comando de deploy

Na aba Deploy, escolha RKLLM Runtime e copie os comandos. Cole no SSH da sua Radxa Rock 5B:

$ git clone https://github.com/airockchip/rknn-llm
$ pip install rkllm-toolkit==1.1.4
$ rkllm-convert --model Qwen/Qwen2.5-1.5B-Instruct \
    --quantization w4a16 --platform rk3588 \
    --output qwen25-1.5b.rkllm
$ ./rkllm_server --model qwen25-1.5b.rkllm --port 8080

Em 4 minutos você tem um servidor LLM rodando localmente, com API OpenAI-compatible em localhost:8080.

Conceitos básicos

Workspace

Cada conta vem com um workspace. Workspace agrupa projetos, times e billing. No plano Free você tem 1 workspace; no Pro até 3; no Enterprise ilimitado.

Projeto

Um projeto representa uma placa eletrônica. Contém:

  • Layout PCB (componentes, trilhas, layers)
  • BOM (Bill of Materials)
  • Configuração do modelo IA destilado
  • Comandos de deploy gerados
  • Histórico de versões
  • Comentários e revisões

Template

Um template é um projeto pré-configurado de uma placa real (RK3588, Jetson Orin, Coral, Hailo, etc). Você pode forka-lo e personalizar.

Modelo destilado

Um modelo de IA quantizado e otimizado para rodar em hardware com recursos limitados. Exemplos suportados:

Plataforma · Rockchip RK3588

SoC octa-core fabricado em Samsung 8nm LP, com NPU dedicado de 6 TOPS. Plataforma open-source mais usada hoje para rodar LLMs destilados na borda.

CPU4×Cortex-A76 @2.4GHz + 4×Cortex-A55 @1.8GHz (big.LITTLE)
NPU6 TOPS INT8 · 3 núcleos independentes
GPUMali-G610 MP4 @1GHz · Vulkan 1.2 · OpenCL 2.2
RAMLPDDR4/LPDDR4X até 32GB
TDP~12W pico (recomendado heatsink + fan)
Placas compat.Radxa Rock 5B, Orange Pi 5+, Banana Pi M7, Khadas Edge2

📌 Dica: Use o template RK3588 Edge LLM Board para começar. Já vem com layout PCB, BOM e 8 modelos LLM pré-configurados.

Deployment · RKLLM Runtime

Runtime oficial da Rockchip para inferência de LLMs no NPU. Aceita modelos Qwen, Llama, Phi-3, DeepSeek, Gemma, ChatGLM, InternLM, Mistral.

Instalação

$ git clone https://github.com/airockchip/rknn-llm
$ cd rknn-llm
$ pip install rkllm-toolkit/packages/rkllm_toolkit-1.1.4-cp310-cp310-linux_x86_64.whl

Quantização

Converte modelo HuggingFace para formato .rkllm com quantização W4A16 (pesos INT4, ativações FP16):

$ rkllm-convert \
    --model Qwen/Qwen2.5-1.5B-Instruct \
    --quantization w4a16 \
    --platform rk3588 \
    --output qwen25-1.5b.rkllm

Servir

$ ./rkllm_server \
    --model qwen25-1.5b.rkllm \
    --port 8080 \
    --max-ctx 4096

Cliente

$ curl http://localhost:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
      "model": "qwen",
      "messages": [{"role": "user", "content": "Olá!"}]
    }'

Repositório: github.com/airockchip/rknn-llm

Deployment · Ollama

Servidor LLM com auto-quantização GGUF. Roda em CPU + Mali GPU no RK3588 (sem NPU). Mais lento que RKLLM, mas com catálogo enorme e API OpenAI-compatible pronta.

$ curl -fsSL https://ollama.com/install.sh | sh
$ ollama pull qwen2.5:1.5b-instruct-q4_K_M
$ ollama serve  # API em :11434
$ ollama run qwen2.5:1.5b "Olá!"

Performance esperada no RK3588 (sem NPU): 6-8 tok/s para Qwen2.5 1.5B.

API REST

A API NeuroPCB permite gerenciar projetos, exportar Gerber, rodar simulações e integrar no seu CI/CD. Disponível nos planos Pro (100 req/min) e Enterprise (ilimitado).

Autenticação

Todas as requisições usam Bearer token. Gere chaves em Settings → API Keys.

$ curl https://api.neuropcb.io/v1/projects \
    -H "Authorization: Bearer npcb_live_•••••••"

Endpoints

MétodoEndpointDescrição
GET/v1/projectsListar todos os projetos
POST/v1/projectsCriar projeto a partir de template
GET/v1/projects/:idDetalhes do projeto
POST/v1/projects/:id/exportExportar Gerber/BOM/PDF
POST/v1/projects/:id/simulateRodar simulação térmica
POST/v1/copilot/askPerguntar ao AI Copilot
GET/v1/templatesListar templates disponíveis
GET/v1/modelsListar modelos LLM com benchmarks

Exemplo · criar projeto

$ curl https://api.neuropcb.io/v1/projects \
    -H "Authorization: Bearer npcb_live_•••••••" \
    -H "Content-Type: application/json" \
    -d '{
      "name": "Voice Assistant V2",
      "template": "tpl-rk3588",
      "tags": ["voice", "edge", "qwen"]
    }'

CLI · npcb

O CLI npcb permite gerenciar projetos do terminal, ideal para CI/CD e automação.

$ npm install -g @neuropcb/cli
$ npcb login
$ npcb new my-board --template rk3588
$ npcb export gerber --output ./fab
$ npcb deploy --target radxa-rock-5b@192.168.1.10
